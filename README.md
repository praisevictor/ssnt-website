# SSNT Website — Starter Frontend

## Project structure

```text
ssnt-website/
├── index.html
├── style.css
├── script.js
└── assets/
    └── ssnt-logo.jpeg
```

## Run locally

Open `index.html` in a browser.

For development, VS Code + Live Server is recommended.

## Important placeholders

The first version intentionally contains placeholders for:
- Actual SEN solution names
- Solution descriptions
- Prices
- Contact email
- Phone number
- Location
- Social media links
- Verified testimonials

These should be replaced with the organisation's real information before launch.

## Current functionality

- Responsive desktop/tablet/mobile layout
- Dark/light mode with localStorage persistence
- Mobile navigation
- Animated impact counters
- Scroll-reveal animations
- Active navigation indicators
- Expandable "View All Solutions" section
- "See Less" collapse interaction
- SSNT logo integrated into the design
